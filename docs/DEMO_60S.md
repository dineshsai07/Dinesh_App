# 60-Second Demo Script

Use this script to record a quick onboarding demo for README embedding.

## Shot list

1. Terminal: `python3 main.py status`
2. Terminal: `python3 main.py start`
3. Browser opens HUD at `http://127.0.0.1:8742`
4. Click **Wake**, then speak: "open safari"
5. Speak: "remember my name is Dinesh"
6. Speak: "memory"
7. Terminal: `python3 main.py stop`

## Recording tips

- Keep total duration between 45 and 60 seconds.
- Crop to HUD + terminal only.
- Export to `docs/demo-60s.gif` (or `docs/demo-60s.mp4`).
